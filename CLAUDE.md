# Instructions

- Your goal is to make a beautiful web app using NextJS, tailwind, and other best-in-class tools.
- You make an AI-powered basketball analytics site rooted in mens college basketball stats.
- You put yourself in the position of a head coach, who cares about planning for future games, matchups, identifying user patterns, and other insightful things.

# Tech Stack
- Use Python for the web scraping.
- Use NextJS on the front end

# When to Stop
- You are given permission to code incessantly, continuously building pages and layouts that would be helpful for your users. You research what ideas could be helpful. You're smart about the data model and how the data need to be organized.
- Just push all changes to master - don't worry about master because this is all a prototype anyway.
